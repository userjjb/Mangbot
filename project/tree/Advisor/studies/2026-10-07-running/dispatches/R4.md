# Dispatch: every run in dive03/dive04 and how it went
- Brief: list every Pilot run (dive03, dive04), outcomes by context, real speeds, the two worst incidents, walking time a run could cover.
- Clerk run: 2026-10-07; sources: runs/pilot/dive03+dive04 events.jsonl and decisions.jsonl (full), pilot/mover.py, server cmd1.c, cmd2.c, dungeon.c, xtra2.c, net-game.c, tables.c. CSV: scratch/R4_runs.csv (14,100 runs, one per row). Scripts: scratch/r4_*.py.

## Answer
- 14,100 runs (`custom . dir=N`): Dive03 7,315, Dive04 6,785. Dungeon 13,194, town 559, wilderness 347. **Only 18% of dungeon runs moved 2+ tiles.** 82% were "starved": 0 or 1 tile, then the pilot's 0.5 s timeout walked (~0.56-0.6 s/tile, the same as walking).
- A run that starts is ~5x faster: 0.107 s/tile in town (9.35 t/s), 0.133 s at DL2-15, against walking at 0.507 s (town) to 0.67 s (DL10-15). Effective speed with launch and stop: town 4.8-6.9 t/s, dungeon multi-tile 3.2-3.5 t/s.
- Both incidents are one mechanism: at night in town a `free_run(keep_goals=True)` is an unbounded run over unknown ground, and it uses no replan budget.
- A run could cover only ~1-2% of active time; most walking is 1-2 tile hops.

## Contradictions and surprises
- The brief says run commands are in decisions 'act'; they are only in events acks.
- "94 runs" understates incident B: 185 runs.
- a516853's guess "probably also the 4-min pacing near store 5" is confirmed, and the cause is the free run, not only night (findings 3, 6).
- Runs sent right after a step mostly do nothing in the dungeon; the "2.9 t/s" figure is a best case.
- Dive03 had an earlier edge escape on 09-25 (finding 5).
- Depths 33, 37, 77, 93, 113 in decisions are wilderness (signed-byte wrap, world.py:209); I treated depth >21 or <0 as wilderness.

## Leads
- `_free_tick`'s 0.5 s timeout (below the 0.6-0.67 s energy period) or a "sent <0.15 s after a step" gate would stop starved runs; untested.
- In the dungeon a free run also ignores where the path turns off; I did not measure overshoot there.
- Per-run map snapshots would separate lit rooms, dark rooms and corridors.
- After a516853, did surface walking get slower? Not studied (dive04 after 09:25 has only 3 town stretches of 4+).
