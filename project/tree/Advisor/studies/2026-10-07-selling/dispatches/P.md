# Dispatch: unknown POTIONS (quaff code, classes, awareness)
- Brief: what each of the 54 potion kinds does when our warrior quaffs it out of combat, how it is classed, and how awareness works.
- Clerk run: 2026-10-07; sources: server/cmd6.c, use-obj.c, spells1.c, spells2.c, xtra2.c, dungeon.c, object1.c, object2.c, mdefines.h, birth.c, save.c, load2.c, init2.c; lib/edit/object.txt; Advisor/data/identify/kinds.csv

## Answer
Quaffing is `do_cmd_quaff_potion` (cmd6.c:155) -> `use_object` -> `quaff_potion` (use-obj.c:241-712). Awareness is NOT automatic: the flavour becomes aware only if the effect sets `*ident` (a visible change). A quaff with no visible effect marks the kind "tried" only, and the potion is still consumed. Only 2 kinds can kill (Death, Detonations; Ruination cannot kill 135 HP). Costly harm is stat drain (fixed by 300-gold Restore potions; Ruination is not fixable that way) and Lose Memories. Awareness is per player, saved, and global flavours are server-wide. The full 54-row table is in `/projectnb/jbrcs/mangband/Advisor/studies/2026-10-07-selling/scratch/P_potions.csv` (columns: sval, potion, level, alloc, kind_cost, effect, class, fix, aware_on_quaff).

## Findings
1. Time unit. "Ticks" below = one timed-effect decrement every `time = level_speed/1000` game turns (dungeon.c:1112, 1183, 1317-1352); game turns run at FPS 75 (github/mangband.cfg:67; default 12 at variable.c:182). Per prior study S3 (49 game turns at 500 ft, 57 at 1500 ft) one tick = about 0.65-0.77 s real. Timers are game-time, so being slowed does not stretch them. [SEEN code; tick length REPORTED from the shops study]
2. Quaff flow (cmd6.c:196-232): `ident=FALSE`; `use_object`; `object_tried()` ALWAYS (cmd6.c:219-222); `if (ident && !object_aware_p) { object_aware(); gain_exp((lev + clvl/2)/clvl) }` (cmd6.c:225-229); potion consumed (cmd6.c:238-252). Exp bonus for first ID is tiny (e.g. level-15 potion at clvl 10 gives 2). [SEEN]
3. "Tried" state exists: `kind_tried[]` (mdefines.h:2668), shown as "tried" in the item name when unaware (object1.c:2036), saved (save.c:302-303). A tried kind still sells at the unaware base value 20 (object2.c:1075-1090). [SEEN]
4. All 54 potions carry EASY_KNOW (object.txt, e.g. N:245 F:EASY_KNOW), so once aware they count as "known" (`object_known_p`, mdefines.h:2674-2677) and sell at the real kind cost. [SEEN]
5. Set functions return TRUE only when a state switches on or off (e.g. set_hero xtra2.c:683-684, set_poisoned 247-248, set_slow 526-527, set_cut 1549). So with no monsters and full HP the following do NOT identify: CLW/CSW/CCW/Healing/*Healing* (no HP missing, nothing to cure), Slow Poison, Neutralize Poison, Boldness (not poisoned/afraid), all Restore stat/Restore Life Levels (nothing drained), Restore Mana (warrior msp 0: never), Experience only if exp<max, Sleep with Free Action, Poison/Blind/Confusion only with the matching resist, a stat-drain potion only if the stat was already 3. Unidentified ones stay "tried"; the Advisor should treat "quaffed, still unaware" as meaning one of that set. [SEEN use-obj.c:241-712]
6. Always-ident (visible every time): Water/Apple/Slime Mold, Salt Water, Ruination, Detonations, Death, Life, Enlightenment, *Enlightenment*, Self Knowledge, Augmentation (if any stat <18/100), Lose Memories (if exp>0), stat-gain potions (unless maxed), Heroism, Berserk, Speed (if not already fast), Resist Heat/Cold, Infravision, Detect Invisible, Slowness (if not already slow). [SEEN]
7. Awareness is per player: `p_ptr->kind_aware[]` (mdefines.h:2662), allocated per character (birth.c:1217), saved/loaded (save.c:302, load2.c:1968). Flavour-to-kind mapping is server-global (`seed_flavor`, dungeon.c:2455, save.c:1591). A new character wipes awareness (birth.c:609-610, then sets unflavoured kinds aware, birth.c:1366). Normal death makes a ghost of the same character (xtra2.c:2796-2802), keeping awareness; ironman/NO_GHOST death goes to `player_funeral` (xtra2.c:2776-2779), so the character is gone and a new one starts blank [INFERRED for the funeral deleting the character]. Resurrection halves exp (xtra2.c:~2862-2867) but not awareness.
8. Lethal: Death = `take_hit(5000)` (use-obj.c:392-398; object.txt N:415 says only invulnerability saves you). Detonations = damroll(50,20) (range 50-1000, mean 525) + stun +75 + cut +5000 (bleeds 3 HP/tick, cut>200, dungeon.c:1211-1215) (use-obj.c:381-390): lethal for 135-300 HP in all but astronomically rare rolls. Ruination = 10d10 (10-100) + dec_stat(25, permanent) on all six stats (use-obj.c:331-343): cannot kill a 135-HP warrior from full HP. Levels: Ruination 40, Death 55, Detonations 60 (kinds.csv).
9. Permanent stat loss is not restored by level-up or time: grep finds no `res_stat` in check_experience or any periodic code; the only callers are the Restore/Life/stat-gain potions and the priest spell (spells2.c:316-345; x-spell.c:1988-2002; xtra2.c has none). Drain potions (Weakness/Stupidity/Naivety/Clumsiness/Sickliness/Ugliness, svals 16-21) call `dec_stat(stat,10,FALSE)`: current drops, max stays (spells2.c:271-308; spells1.c:1162-1255). <=18: -1 point; above 18: loss at least 5 internal units (min amount/2), floor 17/18. Fix = the matching Restore potion: Alchemy shop stocks all six (init2.c:1259-1266), base 300 each (kinds.csv). Ruination uses permanent=TRUE: both cur and max fall (-2 each for stats <=18, at least -12 internal above 18); Restore only returns cur to the lowered max. Only stat-gain potions raise it. [SEEN]
10. Lose Memories: if no Hold Life and exp>0, `lose_exp(exp/4)` (use-obj.c:320-329); may drop levels (xtra2.c:1812-1836). Fix: Restore Life Levels (Temple stock lines 1215-1216 are RESTORE_EXP; base 400) or just earn it back: while exp<max_exp, gain_exp adds the full amount to exp but only 10% to max_exp (xtra2.c:1928-1940), so exp catches up at about 90% of each kill's gain. [SEEN]
11. Real-time risks. Sleep: paralysed 4-7 ticks (`randint0(4)+4`, use-obj.c:308-318; object.txt D line says "3+1d4", which is wrong), about 2.6-5.4 s; skipped entirely with Free Action (we have none). Paralysis zeroes energy (dungeon.c:987-988). Salt Water: food = PY_FOOD_STARVE-1 = 99 (mdefines.h:247), poison cured, paralysed +4 ticks via set_paralyzed directly, so Free Action does not help (use-obj.c:261-270). Aftermath: food 99 is below FAINT (500): every tick, 10% chance to faint 1-6 ticks, bypassing Free Action (dungeon.c:1262-1276); regen 0 below 100; starvation damage (100-food)/10 per digestion step, one step per 10 ticks, 20 food each at normal speed (dungeon.c:1119-1170); digestion does not run in town (dungeon.c:1123-1127) but the faint roll does. So after Salt Water, eat at once (a food item or Satisfy Hunger scroll). Blindness 100-199 ticks (about 65-150 s) blocks reading scrolls; CLW cures it. Confusion 15-34 ticks; Slowness 16-40 ticks; Poison 10-24 ticks at 1 HP/tick. [SEEN]
12. Throwing/breakage: potions always break when thrown (breakage_chance 100, cmd2.c:3397-3402), with no potion effect applied; the only potion-specific code is a throw at a house door (cmd2.c:4086, paints a colour). Cold attacks destroy potions in the pack (hates_cold, spells1.c:~761-770). No gold value in throwing. [SEEN]
13. Value lost by quaffing (kind_cost): Healing 300, *Healing* 1500, Life 5000, Strength-type 8000, Augmentation 60000, Experience 25000, Enlightenment 800, *Enlightenment* 80000, Self Knowledge 2000, Restore Mana 350, Charisma 1000, Speed 75, CCW 100, Berserk 100. The stat-gain/Augmentation/Experience/Life/Enlightenment effects are permanent or useful, so quaffing them is GOOD but destroys 30-46% of that value in shop terms. [SEEN kinds.csv]

## Contradictions and surprises
- object.txt D text for Sleep says "3+1d4 turns"; code is 4-7 (use-obj.c:313).
- Salt Water is more dangerous than its text suggests: faint rolls bypass Free Action, and set to starving (99), not just hungry.
- Brief's "Restore Charisma/other restore potions at Alchemist": confirmed. Restore Life Levels is at the Temple, not Alchemist.
- Contradiction of "known = real value": all potions are EASY_KNOW, so aware means known. Nothing in the brief's shared facts contradicted otherwise (unaware potion base 20 confirmed, object2.c:1089).
