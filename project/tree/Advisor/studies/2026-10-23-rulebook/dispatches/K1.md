## Answer
Object power is rolled in apply_magic from f1=min(75,lev+10), f2=min(20,f1/2). The roll gives power 2 (great), 1 (good), 0, -1 or -2. Bonuses come from m_bonus(max,lev), a normal draw around max*lev/128. Egos are only added for power +2 or -2 on weapons, ammo, bows, diggers and armour. They are picked by rejection sampling, so P(ego) is proportional to 1/rarity among eligible egos. Almost all egos have level 0, so depth barely gates them. Pseudo-ID covers only weapons, ammo, bows, diggers and armour (never rings, amulets or lights). Heavy classes (warrior, rogue, paladin) get excellent/good/average/cursed/worthless. Light classes (mage, priest, ranger) get only good/cursed/broken, or nothing. Random artifacts are OFF in both configs.

   Magic ammo (sval SV_AMMO_MAGIC) returns at once, always +0,+0 (:3193). Never "good" as a kind (:3507). f2 reaches its cap of 20 at lev>=30; f1 reaches 75 at lev>=65, where P(great)=75%*20%=15% (matches comment :3173).

4. **Ego pick** [SEEN] (check_ego :2381-2423; loops :2546-2556 and :2653-2663)
```
for up to 999 tries: idx=randint0(e_max)    # e_max=136 (lib/edit/limits.txt:27); indices with no entry never match
   accept idx if: o.tval in e.tval[0..2] AND e.min_sval<=o.sval<=e.max_sval AND lev>=e.level
        AND randint0(e.rarity)==0
        AND NOT (power>1 and e has LIGHT/HEAVY/PERMA_CURSE) AND NOT (power<-1 and e lacks a curse flag)
```
   So P(ego e | power +-2, tval, sval, lev) = (1/rarity_e) / sum over eligible egos of 1/rarity. Per-try acceptance is sum(1/rarity)/136, so a miss after 999 tries is rare (about 0.04% for diggers, with only Digging eligible below level 20, up to about 1e-12 for helms). Dragon armour returns before the ego search (:2602-2611), so it never gets egos. Power -2 gets an ego only if a curse ego exists for that tval. Cursed egos exist for body armour, shield, helm, crown, cloak, gloves, boots, hafted/polearm/sword (Morgul), bow (Nazgul) and ammo (Backbiting). None exist for digging; that item just stays -2 without an ego. Rarity 1 egos carry a lot of weight (Resist Acid/Lightning/Fire/Cold on body armour and shield, Stealth, Enveloping, Vulnerability, Digging, Accuracy, Power on bows, Backbiting). Nearly every ego is level 0. Level-gated egos: Preservation 60, Night and Day 35, Magi cloak 30, Thievery 40, Combat 50, Gondolin 30, Fury 40, Earthquakes 20, Elvenkind boots 60, Lothlorien 50, Haradrim 50, Buckland 40, Holy Might ammo 40 (all in the CSV).

9. **Artifacts** [SEEN] (object2.c:2205-2294, 2124-2195)
```
make_artifact(Depth,o):  (power>=2 only, 1 roll; great drops 4 rolls)
  Depth==0 or o.number!=1: fail
  for a in a_info[16..]: skip if cur_num; skip unless a.tval==o.tval and a.sval==o.sval
     if a.level>Depth: need randint0((a.level-Depth)*2)==0     # uses real DUNGEON depth, not lev
     need randint0(a.rarity)==0
     skip if any player on this level has a_info[i] > cfg_preserve_artifacts(3)
     -> artifact, first hit wins
```
   There is no upper-depth cutoff. The "Depth>level+20" test (:2155) gives d<0, and randint0(d<=1) returns 0, so it always passes (z-rand.c:162). The roll hits only for the exact base kind of the artifact. So P(a given artifact) is roughly P(power 2) x P(that base kind) x 1/rarity.
   Specials (the 15 INSTA_ART indices 1-15: Phial, Elendil, Thrain, Carlammas, Ingwe, Dwarves, Westernesse, Barahir, Tulkas, Narya, Nenya, Vilya, One Ring, Elessar, Evenstar):
```
in place_object: if randint0(good ? 10 : 1000)==0:  make_artifact_special
   for i in 1..15: skip if made; (out-of-depth: randint0((a.level-Depth)*2)); need randint0(a.rarity)==0;
      base kind level > object_level => extra randint0((klevel-object_level)*5)   # first success wins
```
   Floor items therefore have a 1/1000 gate per object, and DROP_GOOD/vault "good" objects have 1/10. Phial (artifact.txt:76-80 `W:5:5:10:10000`): level 5, rarity 5. Its base kind (object.txt:3989-3994, `W:5:0`, no A: line) is never allocated normally. So P(Phial per floor object at depth>=5) is about 1/1000 x 1/5 = 1/5000 (less if an earlier special did not fire; Phial is first in the loop so it is not displaced). Above depth 5 it needs an extra 1/((5-D)*2) roll. Artifacts are "special"/"terrible" under heavy pseudo-ID (see 11).

## Contradictions and surprises
- None against the brief. Comment at object2.c:3166-3173 agrees with the code.
- Nearly all ego_item.txt entries are level 0 (the file's own W: depth). So egos are NOT depth-gated in 1.5.3; depth only enters through f1/f2 and m_bonus..
- Weapon bonuses for ego items are in addition to the power-2 bonuses (2 x (randint1+m_bonus)), then the ego max_h/d are added.
- check_ego chooses uniformly over e_max entries before the rarity test, so rarity-1 egos dominate any tval where they exist.
- Pseudo-ID: Mage has no sense improvement flag, so the mage effectively never pseudo-IDs (unlike Vanilla).
- Phial kind has alloc rarity 0 in object.txt, so it can only appear through the INSTA_ART/special path.
