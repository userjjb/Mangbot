**D8, damage attribution: yes, one function in `logs.py`.** Use this definition:
- **HP drops (from damage_mix):** consecutive records less than 5 s apart with the same max HP. The scorecard's
  10 s gap merges separate hits, and a max-HP change (level-up, CON, Hero/Berserk) isn't damage.
- **Which messages count (from damage_mix):** attack messages from 0.6 s before the drop's first record to 0.2 s
  after its last. 0.6 s is one game block (TICK_S 0.625). The scorecard's 1 s lookback reaches into the block before.
  Split the drop evenly over those messages, as both scripts do now.
- **Classify and name each message once:**
  - Melee: damage_mix's MELEE pattern.
  - Ranged: damage_mix's RANGED pattern plus the element, **and** the monster's name when the message gives one
    ("The X breathes/casts/fires/hurls/spits"). damage_mix drops the name today. The card needs it, since breathers
    are most of the big hits.
  - "It"/"Something": name `unseen`. Damage with no attack message: name `unattributed`, category `other`.
- **Return** one row per (drop, message): `t`, `amount`, `category` (hurt/melee_other/element/other), `monster` (name,
  unseen or unattributed), `depth`. damage_mix filters on depth and sums by category. The card sums by monster for the
  mission window.
- **Equal totals:** yes, the card's per-monster totals should equal the mix's for the same window and depths. Keep
  `unseen` and `unattributed` in the card, so its rows add up to all HP lost, not just the named part. Show the top 8
  plus those two.
- Regenerating past cards is fine.
